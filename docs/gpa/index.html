คำนวณเกรดเฉลี่ย (GPA / GPAX)

ใส่หน่วยกิตและเกรดของแต่ละวิชา เพื่อดูเกรดเฉลี่ยเทอมนี้ และใส่เกรดสะสมเดิมเพื่อดู GPAX ใหม่

วิชาหน่วยกิตเกรด
เกรดสะสมเดิม (ไม่บังคับ)

วิธีคิดเกรดเฉลี่ย

GPA = ผลรวม (หน่วยกิต × ค่าเกรด) ÷ ผลรวมหน่วยกิต

ค่าเกรด: A = 4, B+ = 3.5, B = 3, C+ = 2.5, C = 2, D+ = 1.5, D = 1, F = 0 ส่วนใหญ่ตัดทศนิยมเหลือ 2 ตำแหน่งโดยไม่ปัดขึ้น

GPAX (เกรดเฉลี่ยสะสม) คิดจากทุกวิชาที่เรียนมาทั้งหมด ไม่ใช่การเฉลี่ย GPA ของแต่ละเทอม

คำถามที่พบบ่อย

ทำไม GPAX ไม่เท่ากับค่าเฉลี่ย GPA ของทุกเทอม?

เพราะแต่ละเทอมมีหน่วยกิตไม่เท่ากัน GPAX ต้องถ่วงน้ำหนักด้วยหน่วยกิต

วิชาที่ได้ S/U หรือ P นับไหม?

ไม่นับในเกรดเฉลี่ย ไม่ต้องใส่วิชานั้นในตาราง

เกรดเท่าไหร่ถึงได้เกียรตินิยม?

มหาวิทยาลัยส่วนใหญ่กำหนดเกียรตินิยมอันดับ 1 ที่ 3.50 ขึ้นไป และอันดับ 2 ที่ 3.25 ขึ้นไป โดยต้องไม่เคยได้ F หรือ D ตามเงื่อนไขของแต่ละสถาบัน
