💑 เกมประจำสายคู่รัก

วางมือถือแนวตั้งไว้ระหว่างสองคน คนหนึ่งใช้ฝั่งบน อีกคนใช้ฝั่งล่าง รอจอเป็นสีเขียวแล้วแตะฝั่งตัวเองให้ไวที่สุด

วิธีเล่นดวลความไว

  1. วางมือถือราบระหว่างสองคน แต่ละคนหันเข้าหาฝั่งของตัวเอง
  2. แตะเพื่อเริ่ม จอจะเป็นสีแดง รอให้เปลี่ยนเป็นสีเขียว
  3. แตะฝั่งตัวเองให้เร็วที่สุด ใครแตะก่อนจอเขียวแพ้ทันที
  4. คนแพ้ทำภารกิจหวานๆ ใครชนะครบ 3 รอบก่อนชนะทั้งแมตช์

คำถามที่พบบ่อย

เล่นกับเพื่อนได้ไหม?

ได้ แค่ภารกิจบางข้อเป็นแนวคู่รัก ข้ามหรือเปลี่ยนเป็นดื่มแทนได้

วัดเวลาแม่นไหม?

วัดเป็นมิลลิวินาทีจากตอนที่จอเปลี่ยนสี ใช้ตัดสินได้แน่นอน
