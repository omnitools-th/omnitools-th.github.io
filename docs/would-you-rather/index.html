วิธีเล่น

นับ 1-2-3 ทุกคนยกมือซ้าย (เลือกข้อบน) หรือมือขวา (เลือกข้อล่าง) พร้อมกัน ฝั่งที่มีคนน้อยกว่าโดนลงโทษ แล้วให้แต่ละฝั่งเถียงกันว่าทำไมเลือกแบบนั้น
