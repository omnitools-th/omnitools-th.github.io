นับวัน คำนวณวันระหว่างวันที่

หาว่าสองวันห่างกันกี่วัน มีวันทำงานกี่วัน หรือนับไปข้างหน้า/ย้อนหลังจากวันที่ที่ต้องการ

ระหว่างสองวันที่

บวก / ลบ วัน

ใช้นับวันทำอะไรได้บ้าง

  • นับวันครบกำหนดสัญญา วันครบกำหนดชำระ หรือวันหมดอายุวีซ่า
  • นับวันลา วันทำงาน อายุงาน หรือวันครบทดลองงาน 119 วัน
  • นับถอยหลังถึงวันสอบ วันแต่งงาน หรือวันเดินทาง

โดยปกติการนับระยะเวลาจะไม่รวมวันแรก ถ้าต้องการนับทั้งวันแรกและวันสุดท้าย (เช่น นับวันลา) ให้ติ๊ก “นับรวมวันสุดท้าย”

คำถามที่พบบ่อย

นับวันลาควรติ๊กนับรวมวันสุดท้ายไหม?

ควรติ๊ก เพราะลาวันที่ 1 ถึง 3 คือ 3 วัน ไม่ใช่ 2 วัน

วันทำงานหักวันหยุดราชการให้ไหม?

ยังไม่หัก ระบบนับเฉพาะวันจันทร์ถึงศุกร์ ให้นำวันหยุดนักขัตฤกษ์ในช่วงนั้นไปลบเอง

ทดลองงาน 119 วันครบวันไหน?

ใช้ส่วน “บวก / ลบ วัน” ใส่วันเริ่มงานและจำนวน 118 วัน (วันเริ่มงานนับเป็นวันที่ 1)
