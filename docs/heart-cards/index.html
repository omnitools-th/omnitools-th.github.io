🃏 ไพ่ถามใจ 3 ระดับ

💔 เกมประจำสายเจาะใจ

เริ่มจากคำถามเบาๆ แล้วค่อยลึกขึ้นทีละระดับ ถามคนที่คุณเลือกในวง แล้วให้เขาเป็นคนเปิดไพ่ต่อ

วิธีเล่นไพ่ถามใจ

  1. เริ่มที่ระดับ 1 คนเปิดไพ่เลือกคนในวงแล้วถามคำถามบนไพ่
  2. คนที่ถูกถามตอบ แล้วเป็นคนเปิดไพ่ถามคนต่อไป
  3. เมื่อวงเริ่มเปิดใจ ค่อยขยับไประดับ 2 และ 3
  4. ไพ่พิเศษจะสุ่มโผล่มาเป็นระยะ ให้ทำตามที่เขียน

ไม่อยากตอบข้อไหน ข้ามได้ แต่ต้องโดนบทลงโทษ ฟังกันอย่างตั้งใจ ไม่ตัดสินกัน
