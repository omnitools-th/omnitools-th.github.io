แก้ข้อความที่พิมพ์ลืมเปลี่ยนภาษา

วางข้อความที่พิมพ์ผิดแป้น ระบบเดาทิศทางให้อัตโนมัติว่าต้องแปลงเป็นไทยหรืออังกฤษ แล้วคัดลอกไปใช้ได้เลย

ทำงานอย่างไร

แป้นพิมพ์ไทยแบบเกษมณีกับแป้นอังกฤษ QWERTY ใช้ปุ่มเดียวกัน เมื่อลืมเปลี่ยนภาษา ตัวอักษรที่ออกมาจะเป็นตัวที่อยู่บนปุ่มเดียวกันของอีกภาษา ระบบจะจับคู่ตัวอักษรกลับทีละปุ่มให้ รวมถึงตัวที่ต้องกด Shift

ตัวอย่าง: l;ylfu → สวัสดี, ktdfbd → าะดิดก, ฟหหน → asdf

คำถามที่พบบ่อย

รองรับแป้นปัตตะโชติไหม?

ตอนนี้รองรับแป้นเกษมณี ซึ่งเป็นแป้นมาตรฐานที่ใช้กันเกือบทุกเครื่อง

เปลี่ยนภาษาบนคีย์บอร์ดกดปุ่มไหน?

บน Windows กดปุ่ม ~ (Grave) หรือ Alt+Shift หรือ Windows+Space บน Mac กด Control+Space หรือปุ่ม Caps Lock

ข้อความถูกส่งไปที่ไหนไหม?

ไม่ การแปลงทั้งหมดทำงานในเบราว์เซอร์ของคุณ

เครื่องมือที่เกี่ยวข้อง

แปลงตัวเลขเป็นตัวหนังสือพิมพ์จำนวนเงิน ได้คำอ่านภาษาไทย “บาทถ้วน” ทันทีคำนวณเกรดเฉลี่ย GPAเกรดเฉลี่ยเทอม และ GPAX สะสมนับตัวอักษรภาษาไทยนับตัวอักษร คำ พยางค์ SMS ถูกต้องสำหรับภาษาไทยวงล้อสุ่มชื่อยอดนิยมหมุนวงล้อสุ่มชื่อ จับฉลาก สุ่มของรางวัล สุ่มเลขค่าชาร์จรถ EV เทียบน้ำมันมาแรงชาร์จบ้าน vs ตู้ชาร์จ vs เติมน้ำมัน ประหยัดเดือนละเท่าไหร่โซลาร์เซลล์คืนทุนกี่ปีมาแรงติดโซลาร์บนหลังคาคุ้มไหม ประหยัดค่าไฟปีละเท่าไหร่
