คนทายยกมือถือไว้ที่หน้าผากให้เพื่อนเห็นคำ เพื่อนใบ้ด้วยท่าทางหรือคำพูด แตะจอขวาเมื่อทายถูก แตะซ้ายเพื่อข้าม

เลือกหมวด

แนะนำให้หมุนมือถือเป็นแนวนอน

หมดเวลา!

0 คำ

วิธีเล่นใบ้คำ

  1. แบ่งทีม ทีมละ 2 คนขึ้นไป เลือกหมวดและเวลา
  2. คนทายยกมือถือไว้ที่หน้าผาก หันจอออกให้เพื่อนในทีมเห็น
  3. เพื่อนใบ้ด้วยท่าทาง (หรือคำพูดที่ไม่ใช่คำนั้น) ทายถูกแตะจอฝั่งขวา ข้ามแตะฝั่งซ้าย
  4. หมดเวลาระบบนับคะแนนให้ เปลี่ยนทีมเล่นต่อ ทีมที่ได้น้อยที่สุดโดนลงโทษ

คำถามที่พบบ่อย

มีกี่คำ?

6 หมวด หมวดละ 30 คำ รวม 180 คำ เลือก “สุ่มทุกหมวด” เพื่อให้ยากขึ้น

ใช้การเอียงมือถือได้ไหม?

เวอร์ชันนี้ใช้การแตะจอซ้าย/ขวา ซึ่งแม่นกว่าและใช้ได้กับทุกรุ่น
