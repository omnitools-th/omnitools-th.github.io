# คิดง่าย — เว็บเครื่องมือคำนวณภาษาไทย (หารายได้จากโฆษณา)

เว็บนิ่งล้วน ไม่มีเซิร์ฟเวอร์ ไม่มีค่าโฮสต์ มีเครื่องมือ 10 ตัว: แปลงตัวเลขเป็นตัวหนังสือ, ภาษีเงินได้, ค่างวดรถ,
ผ่อนบ้าน, VAT/หัก ณ ที่จ่าย, อายุ, นับวัน, BMI, ส่วนลด/เปอร์เซ็นต์, เกรดเฉลี่ย

```
build.py          ← ตั้งค่า (ชื่อเว็บ, URL, รหัส AdSense) + เนื้อหาทุกหน้า
src/assets/       ← style.css, app.js (สูตรคำนวณทั้งหมด)
docs/             ← เว็บที่สร้างเสร็จ (อย่าแก้ในนี้ตรงๆ ให้แก้ที่ build.py แล้วรันใหม่)
```

สร้างเว็บใหม่หลังแก้ไข: `python build.py`

## ขั้นตอนที่ต้องทำเอง (ทำครั้งเดียว)

1. **ขึ้นเว็บฟรีด้วย GitHub Pages**
   - สร้าง repo ใหม่ชื่อ `kidngai` บน GitHub แล้ว push โฟลเดอร์นี้ขึ้นไป
   - Settings → Pages → Source: *Deploy from a branch* → Branch `main` โฟลเดอร์ `/docs`
   - เว็บจะอยู่ที่ `https://kaveek1-rgb.github.io/kidngai/`
2. **(แนะนำมาก) ซื้อโดเมนของตัวเอง** ประมาณ 300–500 บาท/ปี เช่น `kidngai.com`
   - AdSense มักไม่อนุมัติเว็บที่อยู่ใต้ `github.io`
   - ใส่โดเมนใน Settings → Pages → Custom domain แล้วแก้ `SITE_URL` ใน build.py → รัน build ใหม่ → push
3. **ให้ Google รู้จักเว็บ**: เข้า Google Search Console → เพิ่มเว็บ → ส่ง `sitemap.xml`
   (ถ้าให้ยืนยันด้วย meta tag ให้ใส่รหัสใน `GOOGLE_VERIFY`)
4. **สมัคร Google AdSense** เมื่อเว็บออนไลน์แล้วสักพัก → ได้รหัส `ca-pub-...` → ใส่ใน `ADSENSE_CLIENT` → build → push
   ระบบจะใส่สคริปต์โฆษณาอัตโนมัติ (Auto ads) และสร้าง `ads.txt` ให้
5. จากนั้นปล่อยทิ้งไว้ได้ ปีละครั้งควรเช็กว่าอัตราภาษีหรือค่าลดหย่อนเปลี่ยนหรือไม่

## ความคาดหวังที่ตรงไปตรงมา

- Google ใช้เวลาประมาณ 3–6 เดือนกว่าจะเริ่มส่งคนเข้าเว็บใหม่
- โฆษณาในไทยได้ประมาณ 20–80 บาทต่อผู้เข้าชม 1,000 ครั้ง ถ้ามีคนเข้า 1,000 ครั้งต่อวัน จะได้ราว 600–2,400 บาทต่อเดือน
- ไม่มีอะไรรับประกันว่าจะติดอันดับ การเพิ่มเครื่องมือใหม่เรื่อยๆ ช่วยให้โอกาสเพิ่มขึ้น
